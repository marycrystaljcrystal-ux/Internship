HTML5 Semantic Elements

Header

The header contains introductory content such as a website title, logo, or navigation.

Navigation

The nav element contains important navigation links.

Main

The main element contains the primary content of the page.

Section

A section groups related content around a particular topic.

Article

An article represents self-contained content that could be distributed or reused independently.

Accessibility Tip

Use meaningful headings, descriptive link text, labels, keyboard-friendly navigation, and appropriate ARIA attributes when necessary.

ARIA Accessibility

What is ARIA?

ARIA stands for Accessible Rich Internet Applications. It provides additional information to assistive technologies when native HTML semantics are not enough.
